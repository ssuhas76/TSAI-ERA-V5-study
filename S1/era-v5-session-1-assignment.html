ERA V5 Session 1: Assignment

Each section states one claim about how neural networks work, trains small models live in your browser, and shows the evidence. There are no libraries and no server. Every experiment has its own Train, Stop and Reset buttons, an epochs box and a learning rate (default 0.01). Training is full-batch Adam, one update per epoch. Press Train, watch the plots change, then Reset and try other settings.

S1-1 · Activations exist for a reason.

Claim. A model with no nonlinearity can only draw a straight boundary, so it cannot separate two concentric rings; adding one ReLU hidden layer can. Build. 300 noisy 2D points as two rings (inner = class 0, outer = class 1), not linearly separable, fed to (a) a single linear layer + sigmoid and (b) one ReLU hidden layer. What to look for. The linear boundary stays a straight line near chance accuracy; the ReLU boundary wraps the inner ring and accuracy climbs toward 99%. Only the activation changed.

S1-2 · Depth without nonlinearity is a lie.

Claim. Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer; both fail the ring task the same way, and inserting ReLUs between the same five layers solves it. Build. Same ring data; train 1 linear layer, 5 linear layers (no activations), then 5 layers + ReLU. What to look for. The first two panels are both straight lines with matching accuracy; ReLU breaks the tie. The table multiplies each model's five weight matrices into one 1×2 matrix: for the linear stack it reproduces the network to rounding error.

S1-3 · Embeddings learn similarity from nothing but next-token.

Claim. Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens, though similarity was never supplied. Build. A toy language with animals (cat dog cow), fruits (apple mango) and verbs (eat chase see), with templates like ANIMAL VERB ANIMAL and ANIMAL VERB FRUIT, so same-category tokens share next-token distributions. A tiny embedding-to-softmax model learns to predict the next word. What to look for. Projected to 2D, same-category words land together and are each other's nearest neighbours.

S1-4 · Memorization vs generalization, and data closes the gap.

Claim. A high-capacity model on tiny data drives train loss toward 0 while held-out loss stays high; growing the dataset closes the gap. Build. A learnable but noisy classification task with a held-out test set; the same over-parameterized network is trained on 20, 200 and 2000 examples. What to look for. The train/test gap is largest at 20 points and shrinks as data grows. Data is everything.
